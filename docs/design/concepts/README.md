# Concept sheets

Shiori's own mockups, drawn 2026-10-31 from the old app's ideas (not its code) so KaiC could
pick a direction. `concepts.html` is the source; open it in a browser to re-render. The
book titles are public-domain classics plus KaiC's test book's title; the covers are
generated, not real art.

| Sheet | Picked | Recorded in the spec |
| --- | --- | --- |
| `1-shelf.png`: 3D shelf | **B, spine wave** | §6.2 |
| `2-bar.png`: bottom bar | **A, glass lens** | §5.1 |
| `3-settings.png`: Settings tab | **B, summary + grouped rows** | §9 |
| `4-tones.png`: dark mode | **A, neutral charcoal `#1F1F1F`** | §4.2 |
| `5-reader-menus.png`: reader menus | **B, one bottom panel** | §7.7 |
| `6-reader-aa.png`: Appearance sheet | **B, controls inline** | §7.7 |
| `7-reader-info.png`: page info | **B, footer only** | §7.7 |

`reader-concepts.html` is the source for sheets 5–7. Their sample text is 《桃花源记》.

Also decided alongside these:

- **Appearance:** follows the phone by default.
- **Archive codes:** kept (`SH-` serials, `NO.001` spine numbers, section labels), as
  is a very faint background grid (§4.3).
- **Shelf header:** History and Search buttons only (§6.1).

These are direction, not pixel specs. The real screens should look better than the
mockups, not identical to them.

# Reference screenshots

Screenshots of the app KaiC used before Shiori (Wenku8 Flutter), taken on his iPhone 17 Pro Max.
They show the UI ideas Shiori borrows: the 3D spine shelf, the archive look, the reader
chrome and the folded-paper icons. They are a look reference only. Shiori's code is
written from `docs/`, never from the old app's source.

The images stay on this PC. `reference/screens/` is gitignored because the screenshots
show real book covers, which are not ours to publish.

## What's here (2026-10-31)
